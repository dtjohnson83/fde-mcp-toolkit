# Customer Rollout Strategy

## Pilot Scope

Start with one workflow, one user group, and one measurable outcome.

Good pilot:

- one data source
- known users
- known failure modes
- visible owner
- written go-live criteria

Bad pilot:

- all users
- every workflow
- no eval set
- no support path
- no rollback plan

## Rollout Stages

## 1. Discovery

Capture workflow, users, systems, risks, and success metrics.

## 2. Prototype

Build the smallest useful loop with real customer-shaped data.

## 3. Pilot

Run with a small user group. Track failure modes and adoption.

## 4. Harden

Add evals, audit logs, approval gates, monitoring, and support docs.

## 5. Expand

Add users and workflows only after the first loop is stable.

## Go-Live Criteria

- Owner assigned
- Golden cases pass
- Regression cases pass
- Approval gates work
- Audit trail records tool calls and decisions
- Rollback path exists
- Support owner is named
